# A function to list all objects of class genotype in the current environment

A function to list all objects of class genotype in the current
environment

## Usage

``` r
listGenotypes(base = T)
```

## Arguments

- base:

  logical. Indicates whether the user wants to return a list of
  genotypes that were contained in the original base package. Default is
  set to true. If the user wants to return genotypes listed in the main
  environment (genotypes that they have built themselves), they should
  set this parameter to FALSE.

## Examples

``` r
NA
#> [1] NA
```
