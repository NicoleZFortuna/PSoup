# A function for building a network object

This function accepts a list of nodes and a list of genotypes. It will
check if the objects are appropriate, and organise them into a single
object of class network. Will check the network to make sure that all
objects and genotypes have been pointed to, and will return a list of
objects that have not been.

## Usage

``` r
buildNetwork(hormones, genotypes, name)
```

## Arguments

- hormones:

  a list containing objects of class hormone.

- genotypes:

  a list containing objects of class hormone.

- name:

  the name to be given to the network
