# A function that converts an SBGN-ML text file into a network object

A function that converts an SBGN-ML text file into a network object

## Usage

``` r
convertSBGNdiagram(file, networkName)
```

## Arguments

- file:

  a string. A text file with extension .xml containing the markdown
  output of an sbgn diagram.

- networkName:

  a string. The name that you wish to give the network.
